# Omarchy Touchpad & Arabic Keyboard Configuration

A simple `input.lua` configuration for **Omarchy / Hyprland** that provides:

- 🖱️ Normal touchpad scrolling behavior
- 🇪🇬 Arabic keyboard layout support
- ⌨️ Easy switching between keyboard layouts

The `input.lua` file is included in this repository so you can view the complete configuration directly on GitHub.

## Installation

Copy the `input.lua` file into your Hyprland configuration directory:

```bash
cp input.lua ~/.config/hypr/input.lua
```
If i didn't apply after pasing and replacing the old `input.lua` file 
Run this command 
```bash
hyprctl reload
```
